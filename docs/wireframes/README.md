# BusArrival AI - UI/UX Wireframes

This directory contains ASCII wireframe specifications and component layouts for the core application views:

1. [01_login.md](01_login.md) - Split brand & sign-in screen, strength meters, role access indicators.
2. [02_dashboard.md](02_dashboard.md) - Executive & dispatcher overview with KPI cards, sparklines, delay trends, and congestion heatmaps.
3. [03_eta_predictor.md](03_eta_predictor.md) - Passenger and operator prediction interface featuring `EtaCard` with P50/P90 intervals and `RouteLineDiagram`.
4. [04_data_entry.md](04_data_entry.md) - Inline-editable data tables across transit entities and CSV Import Wizard with validation pipeline.
5. [05_models.md](05_models.md) - Model registry, training engine, hyperparameter benchmarks, and feature importance rankings.
6. [06_accuracy.md](06_accuracy.md) - Forecast accuracy dashboard, residual error distributions, and leave-route-out cross-validation.

All layouts strictly adhere to the light theme tokens specified in [../design-tokens.md](../design-tokens.md).
